# Architecture

Pilzatlas BB is an interpretable field atlas, not a secret-spot pinboard.

```text
official geodata + weather + biodiversity + private notes
                         |
                  provenance layer
                         |
      species model + conservation gate + mobility
                         |
                  mission assessment
                         |
              MapLibre + deck.gl + H3
```

Keep habitat suitability, fruiting readiness, observation evidence, evidence confidence, trip quality, conservation/legal state and edibility separate.
